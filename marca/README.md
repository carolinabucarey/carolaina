# Logos de El Ropero de Carolaina

Generados a partir del logo circular original (300 px). Las versiones de más de 300 px están ampliadas: si consigues el logo en mayor resolución, conviene regenerarlas.

| Carpeta | Para qué |
|---|---|
| `logos/transparente/` | Logo circular con fondo transparente, de 16 a 1024 px. Para documentos, presentaciones y diseños. |
| `logos/fondo-crema/` y `logos/fondo-blanco/` | Cuadrados con fondo, para donde no se admite transparencia. |
| `logos/redes-sociales/` | Foto de perfil de Instagram (1080), WhatsApp (640) y Facebook (720); post de Instagram (1080) e historia (1080×1920). |
| `logos/web/` | Favicon, ícono de iPhone (180) e íconos de Android/PWA (192, 512 y maskable). Ya están en el sitio. |
